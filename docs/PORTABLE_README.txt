TABLA FOR WINDOWS - 0.9.0
A little order. A lot more room.

GET STARTED
Extract the complete ZIP, open the Tabla folder and run Tabla.exe.
Keep the _internal folder beside Tabla.exe. Python is not required.

YOUR WORKSPACE
The first workspace is empty. Create a task, take a note or add an event.
Home brings your calendar, boards, tasks and recent notes together.
Settings can add a sample workspace to an empty workspace.

DATA AND BACKUPS
Your real workspace is separate from this app, normally under
%LOCALAPPDATA%/Tabla. Settings displays the exact location.
Use Settings to export a JSON backup that includes referenced attachments.
Daily database snapshots do not include attachment files.
This version does not encrypt your database.

UPDATES
Extract a new release to a separate folder. Your workspace stays in its
separate data folder. There is no automatic updater. This build is unsigned.

MORE HELP
USER-GUIDE.md contains notes, shortcuts, backup and timer instructions.
LICENSE.txt covers TABLA original code under the MIT License.
THIRD-PARTY-NOTICES.md and licenses/ cover bundled third-party components.

All features run locally. No account or internet connection is required.
