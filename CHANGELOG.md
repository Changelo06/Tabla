# Changelog

## 1.0.0

- **Unified Design System & 8 Theme Presets:** Added semantic design tokens (`Daylight`, `Paper`, `Mist`, `Sage`, `Obsidian`, `Graphite`, `Nord`, and `Espresso`) with a visual preview gallery in Settings and a checkable **View → Appearance** submenu.
- **Native Windows 11 Shell:** Replaced macOS-style circles with crisp Windows 11 caption controls (`—`, `□`/`❐`, `×`) preserving Snap Layout hit testing, plus DWM rounded corners, immersive dark mode, adaptive border tinting, and a subtle pinstripe chrome divider.
- **Polished Mini Calendar & Calendar Views:** Redesigned the Home mini calendar and full Month/Week/Day calendar views with framed surfaces, segmented `Month | Week | Day` and `‹ Today ›` controls, monochrome Today badges, monospace timeline hours, dotted half-hour guides, and a live current-time indicator dot.
- **Pomodoro Display Typography:** Upgraded the Focus timer countdown to bundled `Manrope` SemiBold with OpenType tabular lining figures (`tnum`) and centered colon (`case`) so digits stay rock-steady while ticking.
- **Board & Editor Craft:** Streamlined the Board toolbar (`Boards`, `Board | Table` segmented switch), added live Markdown block shortcuts (`# `, `- `, `1. `, `[] `), optical SVG formatting icons, horizontal drag-edge autoscroll, dynamic label chips, and spring-physics note reveals.
- **Performance & Opt-In Feedback:** Downsampled CPU backdrop blur, zero-allocation scroll edge fades, SQL-only `[[link]]` autocomplete, DPR-exact icon caching, gated idle timer polling, and optional tactile micro-sounds in Settings.
