# Changelog

## 0.9.0

- Direct image buttons in note capture and opened notes.
- List controls cycle between bullets, numbers and uppercase letters.
- Saved list formatting and Enter-to-continue behavior.
- Colored Home calendar markers for day highlights and scheduled items.
- Yellow/minimize, green/maximize and red/close window controls.

## Earlier releases

- **0.8.3:** opened notes retain and immediately display their chosen color.
- **0.8.2:** recent Home notes scroll independently on wide layouts.
- **0.8.1:** Home combines calendar, boards, tasks and recent notes in an adaptive column layout.
- **0.7.2:** per-list destinations for completed cards.
- **0.7.0:** independent project and personal boards with retained state and version 2 backups.
- **0.6.3:** expanded card details, checklists, files and comments.
- **0.6.1:** shared rich note capture/editor, autosave status and bounded note previews.
- **0.6.0:** card-first task boards and task-linked focus sessions.

This repository preparation changes documentation, build portability and release tooling; the app remains version 0.9.0.
